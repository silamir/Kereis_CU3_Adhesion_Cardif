Chaque .yaml est une spec OpenAPI autonome. Pour la lire :
  - editor.swagger.io  : File > Import file
  - Redocly            : npx @redocly/cli preview-docs <fichier>.yaml
  - VS Code            : extension « OpenAPI (Swagger) Editor »

Pour generer les clients Java du module externe :
  openapi-generator-cli generate -i <fichier>.yaml -g java \
      --library resttemplate -o target/generated-sources/<nom>

C'est l'entree du generateur decrit au § 2 de docs/stack-technique.md : aucun DTO
ne doit etre ecrit a la main.
